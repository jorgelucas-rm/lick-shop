# Projeto Integrador IV - SENAC 🎉
## Bem-vindo ao repositório do Projeto Integrador IV, desenvolvido como parte da disciplina de Desenvolvimento Web do curso de Análise e Desenvolvimento de Sistemas do SENAC. Este projeto abrange o desenvolvimento de uma aplicação completa, incluindo frontend e backend, com o objetivo de aplicar conceitos avançados de desenvolvimento web em um cenário prático.

## Descrição do Projeto
O Projeto Integrador IV consiste em uma aplicação web que representa um prototipo de um ecommerce 📝. Ele foi construído utilizando tecnologias modernas para demonstrar habilidades em desenvolvimento da equipe, integração de APIs e boas práticas de programação 💻.

## Tecnologias Utilizadas

### Frontend
* [ Vue.js, JavaScript ] 🌐

### Backend
* [ Java, Docker ] 🚀

### Banco de Dados
* [ MySQL ] 💾


## Estrutura do Repositório

* `/frontend`: Contém o código-fonte da interface da aplicação.
* `/backend`: Contém o código-fonte da API e lógica do servidor.

## Como Executar o Projeto
### Pré-requisitos

* Node.js
* [Gerenciador de pacotes, ex: npm ou yarn]

### Execução do Projeto

1. Navegue até a pasta do frontend: `cd frontend`
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run serve`
4. Acesse a aplicação em: `http://localhost:9922` 🌐.
